# Q2D — озвучка клоном голоса

Голос Q2D клонирован из `voice/ref.wav` (17 с, английская речь; расшифровка в `voice/ref.txt`).
Владелец сам дал согласие на клонирование своего голоса и принял лицензии моделей
(OmniVoice — CC-BY-NC, только некоммерческое использование; напоминай об этом, если речь о монетизации).

## 1. Поднять VoiceStudio (каждая новая сессия)

```sh
bash .claude/skills/q2d/setup.sh
```

Скрипт клонирует VoiceStudio в `~/VoiceStudio`, ставит CPU-зависимости (~5 мин), запускает бэкенд
на `localhost:3900`, принимает лицензии моделей и создаёт профиль голоса «Q2D». Последней строкой печатает ID профиля.
Первая генерация дополнительно скачивает модель OmniVoice (~2–3 мин). Повторный запуск безопасен.
Пока идёт установка — коротко скажи пользователю, что ждём.

## 2. Озвучить

```sh
bash .claude/skills/q2d/say.sh "Text here [pause 1s] more text." out.wav English
bash .claude/skills/q2d/say.sh @script.txt out.wav English
```

Использует родной эндпоинт `POST /generate` (паузы и темп работают только там, а не в `/v1/audio/speech`).
Скорость на CPU ≈ 8 с обработки на 1 с аудио — длинные сценарии разбивай по абзацам и запускай в фоне.
Результат отправляй пользователю файлом. Проверяй, что файл — WAV, а не JSON с ошибкой (say.sh это делает).

Эталон английский: английский звучит лучше всего. Русский текст можно (`ru`/`Russian`), но акцент и качество не гарантированы —
для русского лучше попросить 15–30 с русской записи и пересоздать профиль.

## Теги интонации

Реакции (понимает сама модель OmniVoice): `[laughter]`, `[sigh]`, `[surprise-oh]`, `[surprise-ah]`,
`[surprise-wa]`, `[surprise-yo]`, `[question-en]`, `[question-ah]`, `[question-oh]`, `[question-ei]`,
`[question-yi]`, `[confirmation-en]`, `[dissatisfaction-hnn]`.

Разметка VoiceStudio: `[pause 1s]` / `[pause 500ms]`, `[slow]…[/slow]`, `[fast]…[/fast]`,
`[emphasis]…[/emphasis]`, `[speed:1.2]`.

Свободных эмоций словами («скажи злобно») OmniVoice не поддерживает. Интонацию также задают
пунктуация: `...`, `?`, `!`, короткие фразы.

Проверено 2026-11-08: реакции и `[pause 1s]` работают через `/generate`.
